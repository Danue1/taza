=== 세벌식 최종
# 배치는 세벌식 최종(3-91)을 그대로 옮겼다 — libhangul의 자판표(hangul-keyboard-3f)를
# 기준으로 삼았고, 데스크톱에서 치던 손이 그대로 통하도록 숫자열 자리까지 네 줄을 싣는다.
# 시프트가 기호를 내던 자리(세벌식의 숫자열 오른쪽·아랫줄 오른쪽)는 기호가 이미 심볼면에
# 있으므로 시프트를 두지 않는다.
#
# 글자는 **자리를 밝힌 조합용 자모**(초성 U+1100·중성 U+1161·종성 U+11A8)로 적는다.
# 그래서 세벌식에는 새 합성기가 필요 없다 — 초성인지 종성인지를 앞뒤로 추론하지 않으므로
# 도깨비불이 일어나지 않는다. 키캡에 찍히는 글자는 코어가 호환 자모로 옮겨 그린다.
# 각 행 위의 주석이 그 줄의 읽기다.

=== 천지인 : hangul-cheonjiin
# 표준 천지인 판 — 글자 세 열을 기능 키가 좌우에서 감싸는 네 줄 다섯 칸이다. 하늘(ㆍ)·
# 땅(ㅡ)·사람(ㅣ)이 맨 위, 자음은 같은 키를 이어 눌러 갈아 가고(`|`로 이은 것이 그
# 주기다), ㅇㅁ은 아래에 둔다. 네 줄이 곧 키보드 전체 높이라 다른 배열과 저절로 맞는다.
#
# 엔터는 순정처럼 두 줄을 잇는다(`^2`) — 이어진 줄에서 그 자리는 `blank`로 비워 두어야
# 나머지 키가 제자리에 선다.
#
# `→`는 커서를 오른쪽으로 한 칸 옮기며 조합을 끊는다. 같은 키를 이어 누르면 글자가
# 갈리는 배열이라, 같은 자음으로 시작하는 글자를 잇달아 칠 때("가가") 멀티탭 시한이
# 다 되기를 기다리지 않고 손으로 끊는 길이 있어야 한다.
#
# ABC·한글은 그 언어로 곧장 가는 키다(`language:<태그>=<라벨>`). 순정이 지구본과
# 마이크를 두는 왼쪽 아래 칸은 통합 검색면(☺)이 쓴다.
#
# 조합 규칙이 두벌식과 달라(두벌식의 ㅏ 다음 ㅣ는 새 글자지만 천지인에서는 ㅐ다)
# 이 배열만 자기 골격을 밝힌다.
