# 손으로 갖다 놓는 원천

지금은 없다. 일본어 사전(mozc)은 URL로 자동 조달된다 —
`data/languages/japanese/sources/00-mozc.toml`이 판과 해시를 못 박아 두었다.

이 디렉터리는 나중에 이용 신청·로그인을 거쳐야 하는 원천(코퍼스)이 들어올 자리로 남긴다.

## 평가 셋

`data/languages/japanese/evaluation.tsv`는 사전과 같은 배포본에서 온 mozc의 회귀 사례
564문장(읽기 → 정답 표기)이다. 같은 BSD 조건이고 고지는 사전 원천 선언이 함께 덮는다.

**회귀 사례 모음이라 어려운 쪽으로 치우쳐 있다.** 여기서 나온 값을 평균적인 글의 변환
정확도로 읽으면 안 되고, 같은 셋 위에서 A와 B를 견주는 데 쓴다.
